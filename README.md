# The MET Landing Page

A responsive landing page for The Metropolitan Museum of Art.

The project includes museum information, opening hours, exhibitions, online resources, contacts, and responsive navigation.

## Live Preview

[View Live Demo](https://m-berezovskyy.github.io/the-met-landing-page/)

## Technologies Used

- HTML5
- SCSS
- JavaScript
- Parcel
- BEM methodology

## Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/m-berezovskyy/the-met-landing-page.git
cd the-met-landing-page
```

2. Install dependencies:

```bash
npm install
```

3. Start the project:

```bash
npm start
```

## Features

- Responsive layout for mobile, tablet, and desktop
- Burger navigation menu
- Smooth scrolling between page sections
- Museum opening hours
- Exhibition gallery
- Online exploration section
- Contact information and feedback form
- Hover effects and interactive elements
